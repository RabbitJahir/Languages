⚔ Blood God's Vault

PROJECT OVERVIEW & CONTENT

📖 Project Description

Blood God's Vault is a Technoblade-themed e-commerce web application designed for browsing, purchasing, and managing limited edition relics and artifacts. The application features a clean, medieval-inspired interface and supports two distinct user roles: regular shoppers (users) and administrators.

The project is built entirely with vanilla JavaScript, HTML, and CSS - no frameworks or external libraries beyond styling resources and icons. All data is stored locally in the browser using the localStorage API.

🎯 Purpose & Target Users

Purpose: To create an immersive shopping experience for fans of the legendary Minecraft player Technoblade, featuring authenticated relics and battle-worn artifacts.

Target Users:

  • Regular Users: Browse and "purchase" legendary artifacts
  • Administrators: Manage inventory, prices, and stock levels

🏗️ Application Structure

The application consists of three main pages accessible through different entry points:

Page Purpose Access Level Key Features
Login Page
(login.html)		 User Authentication Public Credential validation, session creation, role-based routing
User Shop
(index.html)		 Shopping Interface Authenticated Users Browse items, add to cart, view purchases, price tracking
Admin Dashboard
(admin.html)		 Inventory Management Admin Only Update prices, manage stock quantities, save changes

🛍️ Featured Artifacts

The vault contains four legendary items, each with unique authentication badges:

  • Crown of the Blood God - Authenticated Relic ($1,000 - 10 in stock)
  • Cape of the Blood God - Battle-Worn ($1,000 - 5 in stock)
  • Sword of Legends - Limited Edition ($1,000 - 3 in stock)
  • Potato of Power - Ultra Rare ($1,000 - 1 in stock)

👥 User Roles & Permissions

Regular User Role

  • Browse all items in the shop
  • Add items to shopping cart
  • View cart contents and purchase history
  • See real-time inventory availability
  • View dynamic pricing updates

Admin Role

  • Access dedicated admin dashboard
  • Modify item prices in $50 increments
  • Adjust inventory quantities
  • Save changes with immediate effect
  • Monitor all managed items through editable cards

🎨 Design Theme

The application embraces a medieval fantasy aesthetic with the following design elements:

  • Color Scheme: Deep reds, blacks, and gold accents
  • Typography: Cinzel Decorative for headings, Crimson Pro for body text
  • Icons: Bootstrap Icons for UI elements (cart, logout, inventory)
  • Imagery: Technoblade-themed artwork and relics
  • Branding: "Technoblade Never Dies" dedication in footer

✨ Key Features

  • Session-based authentication with role separation
  • Dynamic shopping cart with quantity management
  • Real-time inventory tracking (sold-out indicators)
  • Price increment system (+$50 per click)
  • Purchase history tracking ("Purchased & Received" section)
  • Toast notifications for admin actions
  • Responsive design with modal cart interface
  • Auto-redirect based on authentication status
  • Local persistence across browser sessions

📱 Responsive Design

The application is designed to work seamlessly across devices with viewport-aware styling. Mobile users can access all features with touch-friendly buttons and appropriately sized interactive elements.

Note: This is a static front-end demonstration. The "purchase" feature does not process real transactions—it simulates purchases using local storage. In a production environment, a backend server and payment gateway would be required.
